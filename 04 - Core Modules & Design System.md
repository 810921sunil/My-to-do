# 🎨 Core Modules & Design System

Back to [[00 - Life OS Vault Hub]]

**Life OS** features a modern glassmorphic dark mode UI built with Tailwind CSS, HSL gradients, dynamic animations, and intuitive time selection.

---

## 🧩 Key Feature Modules

1. **Central Task Manager (`TaskManager.tsx`)**
   - Subtasks checklist, priority badges (Low, Medium, High, Critical), Eisenhower quadrant scoring.

2. **12-Hour AM/PM Time Picker (`TimePicker12h.tsx`)**
   - Custom 12-hour hour:minute selector with AM/PM toggle button.

3. **Rich Notes & File Vault (`NotesFileVault.tsx`)**
   - Rich Markdown note editor, tag organization, and file attachment vault.

4. **Digital Wellbeing (`DigitalWellbeing.tsx`)**
   - Focus session timer, screen time tracking, and habit streaks.

5. **Financial Manager & College Hub (`FinanceManager.tsx`, `College.tsx`)**
   - Income/expense breakdown, GPA tracking, attendance logs, and syllabus schedules.
